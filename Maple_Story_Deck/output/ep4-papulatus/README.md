# 에피소드4 파풀라투스 / 숨겨진 길

- 맵5 퍼즐 포탈 → ep4_map5_ester1 존1(내부189). 모든 이동 화살표 숨김, 서버 좌우 이동 차단.
- 파풀라투스 원본 시계 몸체 → die1 전체 재생 → 같은 엔티티의 비행 본체. 원본 공격/비행/소리.

- MonsterAI의 모든 보스 머리 위 체력바. 픽셀 렌더러와 동기화한 체력/존; 파괴 시 정리.
- ep4_map1_ester1은 기존 ExpBoostBoard로 총60초, 경험치2배, 만료 시 기부 포탈 존136 복귀.
- 숨겨진 길을 나가거나 게임을 일시정지하면 잔여 예산 보존. 새게임/다시하기는 초기화.
- 네 언어 번역: 등장, 페이즈전환, 처치, 숨겨진 길 시간 종료.

verification.json 및 실행 로그/화면 참고. before-*는 수정 전 코드, 맵은 MapBuilder 스냅샷.
tools/apply_*는 일회용 적용 스크립트로 다시 실행하지 말 것.
