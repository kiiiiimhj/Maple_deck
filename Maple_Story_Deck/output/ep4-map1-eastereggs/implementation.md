# EP4 map1 이스터에그

- esteregg_1: O/X 20문제 중 중복 없는 3문제. 오답이면 처음부터 재도전. 퀴즈 중 전투 정지, 닫으면 해당 정지 해제.
- esteregg_2: ep4_map1 잡템 한 종류 50개.
- esteregg_3: ep4_map2 잡템 한 종류 50개. 두 수집 목표는 첫 터치 때 각각 정해짐.
- 퀴즈와 수집 성공은 기존 포션·장착 스킬 강화·이스터에그 추가 보상 경로 사용. 런당 한 번.
- esteregg_4: 보유 골드 100 → 200 → 400 → 600 → 800 → 1000. 취소·잔액 부족은 횟수 미소모. 부족한 예 버튼은 회색이며 클릭 시 부족 안내.
- 기부 보상: 잡템 60%, 빨간 포션 30%, 장착 스킬 강화 10%. 스킬 강화는 여섯 기부 중 최대 두 번, 이후 해당 추첨은 잡템으로 대체.
- esteregg_5: 시작 시 숨김. 기부마다 보상과 별도로 10% 활성화, 여섯 번째는 확정. 이번 범위는 활성화까지.
- 새로 시작·다시하기는 상태 초기화. 이어하기는 상태 유지.
- 한국어·영어·번체 중국어·일본어 텍스트 번역. 문구를 이미지에 넣지 않음.

## 확인

Maker play와 build/normal 로그, 오브젝트 연결·숨김 포탈, 양쪽 실제 잡템 풀을 확인함. 네 언어 문제 키, 정답/오답/재시도, 49개/50개 교환, 중복 요청, 골드 부족, 여섯 기부 비용, 스킬 두 번 제한, 포탈 추첨/확정, 정지 소유권·정리 경로를 격리된 가짜 데이터로 검증함. 실제 계정 재화 소비나 보상 수령은 테스트하지 않음.
