# 보유 다이아·골드 표시 적용

두 재화 표시를 어두운 우드톤과 얇은 금테 프레임으로 통일하고 다이아 상점 더하기 버튼도 초록색 프레임으로 맞췄습니다. 너비 220을 유지하고 높이를 70에서 52로 줄였으며 위쪽 고정 좌표를 -30에서 -16으로 올렸습니다. 가로 좌표와 오른쪽 기본 메이플 월드 UI를 피하는 200 이동 보정은 그대로입니다. 기존 다이아·골드 아이콘, 숫자 표시, 더하기 버튼의 상점 이동 기능을 유지했습니다.

획득 연출은 RewardFlyUI.GetLayerPosOf가 표시칸의 실제 현재 위치를 읽어 도착점을 계산합니다. 세로 이동과 높이 변경으로 달라진 중심 좌표도 자동 반영됩니다. 원래 아이콘 기준점 보정과 가로 도착 보정(-70), 보류·도착·숫자 갱신·반짝이·사운드 코드는 모두 보존했습니다.

메이커 실행 검증: 하단 탭 5개 전환, 스킬·유물 패널과의 간격, 반복 화면 맞춤 후 가로 좌표 유지, 네 가지 가상 캔버스 크기, 더하기 버튼의 상점 이동, 다이아·골드 각각 8개 연출의 도착 반짝이 위치와 숫자 갱신을 확인했습니다. 연출 테스트는 클라이언트 표시만 잠시 조정하고 원복했으며 실제 서버 재화를 지급하거나 차감하지 않았습니다. 빌드·실행 오류 0개. 실제 휴대폰에서의 검증은 하지 않았습니다.

이미지 제작: 내장 image_gen. 원본 스타일 참조는 기존 우드 팝업입니다. 생성 프롬프트와 원본 경로는 generation-manifest.json, 적용 경로와 리소스 ID는 applied-assets.json. 최종 이미지는 frame-compact.png(220×52), plus.png(44×44)이며 실제 적용 비교는 currency-applied-preview.png와 panel-clearance-preview.png입니다.
