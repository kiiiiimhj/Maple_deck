게임오버 다이아 상점 팝업 적용 완료

- 기존 승인된 나무 팝업, 크림 상품 카드, 다이아 배지 및 버튼 자산 재사용. 새 이미지 생성 없음.
- 카드 391x690 / 간격 28 / 스크롤 뷰포트 1300x690 그대로. 스크롤 트랙 1240x45로 줄여 우하단 버섯과 겹침 방지.
- 스크롤 슬라이더의 흰색 채움만 투명 처리. 기존 초록 수정 손잡이 유지.
- 다이아 배지는 기존 X=-262 유지, 220x52 규격과 프레임만 로비에 맞춤.
- 상품 이미지, 이름, 가격, 결제 버튼 이벤트, 스타터 보유 여부 처리 및 이어하기 부족 분기 유지.
- QA에서 재열기 후 첫 상품으로 초기화됨을 화면과 슬라이더 값으로 확인. 네이티브 GetScrollNormalizedPosition의 반환값이 실제 수평 위치와 달라 이 반환값만으로 재열기 판정하지 않음. 스크롤 동작 코드는 변경하지 않음.
- 메이커 클라이언트 미리보기로 첫/끝 상품, 닫기, 재열기 및 안내 자동 숨김 확인. 결제/이어하기 요청이나 플레이 데이터 변경 없음. 실제 모바일 기기 미검증.
