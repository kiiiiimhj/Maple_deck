# 화면에 스며드는 캐릭터 입장 연출

캐릭터가 확대되는 동안 알파가 함께 내려가며 게임 화면에 자연스럽게 스며듭니다. 로딩이 완전히 걷힌 뒤 0.78초 동안 실행하고, 마지막 금빛 잔광까지 사라지면 전투를 시작합니다.

서버는 입장 중 몬스터 이동·공격, 자동 공격, 스폰과 플레이 시간을 정지합니다. 클라이언트의 연출 종료 신호와 서버의 초기화 완료를 모두 확인한 뒤 전투를 해제합니다. 종료 신호는 요청한 사용자와 입장 번호가 일치할 때만 인정합니다.

연출 끄기: `GameEntryFxUI.PresentationEnabled = false`. 연출을 꺼도 로딩이 끝나면 정상적으로 시작합니다.

기존 일반 로딩·게임오버 다시하기 경로는 계속 기존 입장 지연을 사용합니다. 로비에서 시작하는 경우에만 새 완료 조건이 추가됩니다.

`before`는 이번 수정 전 스크립트 백업입니다. 이전 입장 연출 버전의 백업은 `game-entry-silhouette-v1/before`에 있습니다.
