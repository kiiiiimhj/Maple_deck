# 금빛 단풍잎 잔광 수정

중앙에 작은 잎이 나타났다 바로 사라지던 연출을 수정했습니다. 크기가 다른 18개의 금빛 단풍잎이 실루엣 주변에서 시작해 화면 양옆과 위아래로 퍼집니다. 먼저 이동을 충분히 보여주고, 후반부에 회전하며 서서히 투명해집니다.

실루엣의 확대 중 알파 감소는 유지합니다. 전체 길이는 1.04초이며, 모든 잔광이 사라진 뒤 기존 서버의 종료 확인을 통해 전투가 시작됩니다.

끄기: `GameEntryFxUI.PresentationEnabled = false`.

이번 변경 전 스크립트는 `before/GameEntryFxUI.mlua`에 보관했습니다. 새 잎 6개와 개별 투명도 조절용 UI가 추가됐습니다.
