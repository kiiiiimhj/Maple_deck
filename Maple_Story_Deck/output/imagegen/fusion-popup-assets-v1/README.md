# 조합식 팝업

옵션/종료 팝업의 나무판 색상과 아트풍에 맞춘 조합식 팝업입니다.

- `design-preview.png`: 전체 시안
- `board.png`: 글자 없는 투명 배경 패널
- `page_button.png`: 좌우 버튼이 공유하는 투명 배경 버튼 이미지
- `applied-preview.png`: Maker에서 확인한 실제 적용 화면
- `resources.json`: 내 리소스 업로드 RUID와 이름
- `manifest.json`: 이미지 생성 프롬프트, 원본 경로 및 크기
- `verification.json`: 실제 Maker 입력/로그 검증 결과
- `authoring-verification.json`: 기존 구성 보존 및 바인딩 검증

좌우 화살표와 페이지 숫자는 이미지에 포함되지 않은 UI 텍스트입니다. 제목은 기존 로컬라이징 키와 BestFit을 사용합니다.

## 적용

`ui/OptionGroup.ui`의 FusionPanel과 `RootDesk/MyDesk/OptionUI.mlua`에 적용했습니다. 원래 7개 행과 X를 유지하고, 행을 재사용하여 페이지마다 최대 7개 조합을 표시합니다. 현재 캐릭터별 7개이므로 1페이지이며 양쪽 버튼은 비활성 상태입니다. 원본 조합 목록에 8번째 항목부터 추가되면 다음 페이지가 자동으로 활성화됩니다. 첫/마지막 페이지에서 범위를 벗어나지 않고, 다시 열면 1페이지로 돌아갑니다.

페이지 버튼은 88×88 클릭 영역을 유지하며, 보이는 이미지는 60×60으로 하단 테두리 안에 배치했습니다.

## 확인

임시 클라이언트 목록 15개로 1→2→3→2→1 실제 버튼 클릭을 확인했습니다. 마지막 페이지의 남는 행 숨김, 미발견 아이콘/물음표 유지, 빈 목록 처리, X로 옵션 복귀, 다시 열기 및 전체 닫기를 검증했습니다. 임시 목록은 복원했고 데이터 저장 호출은 추가하지 않았습니다. 최종 실행 오류 0건, 빌드 오류 0건이며 기존 빌드 경고 36건이 남아 있습니다.

옵션 이미지 3종도 `../option-popup-assets-v1/`에 저장되어 있고 계정 내 리소스 목록에서 업로드를 확인했습니다.
