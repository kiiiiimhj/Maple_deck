# 빛 단풍잎 입장 연출 v5

단풍잎을 옅은 샴페인 금빛의 투명한 빛 그림으로 새로 제작했다. 큰 모양이 나타난 뒤 자체 빛이 짧게 반짝이고, 작은 빛 단풍 조각이 퍼지는 동안 본체와 조각의 알파가 끝까지 0으로 감소한다.

이미지: `luminous-maple.png` (1254×1254 RGBA), 리소스 RUID `67f080a4c1f14551915d8da7410c4081`. 내장 image_gen으로 생성했으며 최종 프롬프트와 원본 위치는 `generation-manifest.json`에 저장했다.

재생 중 RectSize, 개별 회전·알파 및 컴포넌트 조회를 반복하던 부분을 준비 단계로 옮겼다. 캐릭터 확대는 UIScale을 사용하고, 파티클 24개는 위치만 갱신한다. 파티클의 소멸은 공통 상위 그룹 알파로 제어한다. 텍스처는 입장 전에 로드한다.

기존 전투 대기 흐름을 유지한다. 로딩이 완전히 사라진 다음 연출을 시작하고, 1.36초 연출의 마지막 잔광까지 끝난 뒤 전투와 시간이 진행된다. PresentationEnabled=false로 비활성화할 수 있다.

Maker에서 실제 시작 버튼 경로, 전투 정지와 해제 순서, 비활성화 경로 및 알파 감소를 확인했다. 최대 알파 0.66 → 중간 0.337 → 꼬리 0.026 → 0. 빌드·런타임 오류 0개.

실제 재생을 별도로 측정한 프레임 간격: v4 66개 표본 평균 17.17ms/최대 31ms, v5 76개 표본 평균 17.49ms/최대 21ms. v5 측정에서는 25ms 초과 표본 0개. 단일 Maker PC 실행의 결과이며 모바일 실기 측정은 아니다. 원본 측정값은 `frame-profile.json`과 `actual-start-logs.json`에 저장했다.

`preview.gif` 및 `ingame-preview.gif`는 Maker 화면에서 연출 시점을 고정해 20ms 간격으로 촬영한 모양 비교용 애니메이션이다. 실제 프레임 성능 근거는 위 별도 측정값이다. 원래 mLua와 UIBuilder 스냅샷을 보관해 되돌릴 수 있다.
