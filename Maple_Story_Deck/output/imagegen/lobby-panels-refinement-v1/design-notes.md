# 적용 결과

스킬·유물 두 줄 목록을 40px 내려서 패널 안쪽 상단과 스크롤 위 여백을 약 51px/53px로 맞췄습니다. 아이콘 118px, 딤드 122×126px로 테두리 안쪽에 배치했습니다. 선택 항목은 초록색, 활성 조건의 메인 필터는 조금 더 밝은 초록색으로 구분하며 메인 버튼에 조건 이름을 표시합니다. 네 로비 패널을 은은한 메이플 우드톤으로 통일하고 뒷배경은 조금 밝게 조정했습니다. 스킬·유물 상세창은 동일한 우드 프레임, 기존 네모 X, 회색 비활성 강화 버튼을 사용합니다.
