# 맵 이동 자물쇠 해금 연출

- 적용 완료: 레벨 5 해금 알림, 존15 퍼즐 해금 알림이 기존 ApplyLockState 경로에서 연출을 시작합니다.
- 기존 오른쪽 버튼 자물쇠의 고리가 0.18초 동안 위로 8px 올라가며 기울어져 풀립니다.
- 이어서 0.66초 동안 왼쪽 64px / 아래 80px 이내의 짧은 포물선을 그리며 회전·페이드합니다. 위로 약 22px 상승한 뒤 떨어집니다.
- 원래 RUID 및 흰색 표시 머티리얼을 그대로 재사용했습니다. 기존 이미지의 위/아래를 UI UV fill로 나눠 움직이며 신규 이미지 업로드는 필요하지 않습니다.
- 원래 365개 UI 엔티티, 이동 버튼 크기·앵커·위치, 이동 요청, 서버 해금 조건과 저장 코드는 그대로입니다. 장식 엔티티 3개만 추가했습니다.
- 초기 표시/같은 상태 갱신/맵 전환은 연출하지 않습니다. 중복 해금 알림은 재시작하지 않으며 다시 잠김/버튼 숨김/맵 전환/종료 시 타이머를 정리합니다.
- 실제 메이커: 고리 열림·포물선·페이드·자동 종료·중복 알림·재잠금·맵 전환·숨김 검사 통과. 빌드/런타임 오류 0개. 테스트는 클라이언트 표시만 바꿨고 실제 레벨업·퍼즐 해결·맵 이동·저장은 실행하지 않았습니다.
- 스크린샷은 모습 확인을 위해 클라이언트 연출만 일시적으로 느리게 재생했습니다. 실제 0.84초 재생 및 종료도 별도로 확인했고 원래 속도로 복원했습니다.
- 실물 모바일 기기는 테스트하지 않았습니다. 효과는 기존 오른쪽 버튼의 자식으로 화면 안쪽에 그려집니다.
- 메이커는 편집 모드로 복귀했습니다.
