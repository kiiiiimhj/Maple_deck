# 단풍 모양이 먼저 나타난 뒤 흩어지는 입장 연출

처음부터 큰 금빛 단풍잎이 나타나 약 0.17초간 보인 뒤, 그 자리에서 24개의 작은 단풍잎 빛이 여러 방향으로 흩어집니다. 첨부된 빨간 단풍의 영역을 측정해 작은 조각의 시작 위치로 사용했습니다.

실루엣이 확대 중 투명해지는 동작은 유지했습니다. 전체 연출은 1.16초이며, 잔광이 끝난 다음 서버가 전투를 시작합니다.

색과 그림은 기존 금빛 단풍잎을 유지합니다. 참고 이미지는 위치 측정에만 사용했으며 게임에 새 그림으로 등록하지 않았습니다. 첫 UI 준비가 끝난 뒤 재생 시계를 켜므로 준비 중 연출이 끝나는 일을 막았습니다.

`GameEntryFxUI.PresentationEnabled = false`로 연출만 끌 수 있습니다. 수정 전 스크립트는 `before`에 보관했습니다.
