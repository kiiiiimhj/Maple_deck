# 캐릭터 중심 입장 연출 v6

선택한 캐릭터를 처음에는 알아볼 수 있게 보여준다. 캐릭터는 빠르게 화면보다 크게 확대되고 어두운 실루엣으로 바뀌며, 확대 후반에 알파가 0까지 연속으로 감소한다. 카메라는 캐릭터의 접근에 맞춰 최대 5.5% 당겨졌다가 0.24초 동안 기존 줌 값으로 돌아온다. PC와 모바일의 기존 줌 비율을 시작 시 보관한다.

금빛 단풍잎은 기존 높이의 66%에서 22% 크기로 줄였다. 캐릭터 진입 마지막에 낮은 알파로 나타나는 짧은 잔광이다. 작은 조각의 크기·퍼지는 거리·투명도도 함께 줄였다. 총 재생 시간 1.36초와 마지막 연출 종료 후 전투를 시작하는 기존 대기를 유지한다.

Maker의 실제 캐릭터 선택 확인 버튼 경로에서 실행했다. 캐릭터 표시 중 전투/스폰/시간이 정지함을 확인했고, 마지막 잔광이 끝난 뒤 전투 해제 로그가 발생했다. 카메라의 정상 종료와 중간 Stop 복원을 모두 확인했다. 빌드 및 런타임 오류 0개.

별도 실제 재생 측정 78개 표본: 평균 17.12ms, 최대 19ms, 25ms 초과 0개. Maker PC의 단일 실행 결과다. `ingame-preview.gif`는 실제 인게임 배경과 제작용 연출 렌더러를 20ms 간격의 시점으로 고정해 촬영한 모양 비교 자료이며, 실제 재생 간격은 `frame-profile.json`을 참고한다.

수정 파일: `RootDesk/MyDesk/UI/GameEntryFxUI.mlua`. UI 구조와 기존 생성 그림은 v5 것을 사용한다. 이전 mLua는 `before/GameEntryFxUI.mlua`에 보관했다. `PresentationEnabled=false`로 전체 입장 연출을 비활성화할 수 있다. 검증 후 Maker는 편집 상태로 돌려놓았다.
