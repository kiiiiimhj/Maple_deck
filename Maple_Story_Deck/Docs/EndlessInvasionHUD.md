# 침식 중앙 UI

승인된 둥근 보라 몬스터를 기준으로 만든 배지와 효과 아이콘 6종입니다.
실제 게임 중앙 UI에도 적용했습니다.

- 강인 / 광폭 / 질주 / 범람 / 맹공 / 저주
- 사각 테두리를 포함하는 64×64 PNG가 실제 게임용입니다.
- 128×128 PNG와 투명 원본, 생성 프롬프트도 보관했습니다.
- 게임에서는 56×56으로 표시해 원본보다 확대하지 않습니다.
- 1개부터 3개 효과는 빈 칸 없이 가운데로 정렬됩니다.
- 아이콘 옆에 부호가 있는 수치가 나오며, 버튼을 누르면 효과 이름과 같은 수치를 설명하는 툴팁이 열립니다.
- 같은 아이콘이나 툴팁을 다시 누르면 닫히며, 7초 뒤 또는 UI가 숨겨질 때도 닫힙니다.
- 툴팁과 새 문구는 한국어·영어·번체·간체·일본어·스페인어로 준비했습니다.

## 현재 게임 수치와 표시 데이터 연결

이번 작업은 UI 교체입니다. 새 여섯 효과의 추첨·전투 계산은 구현하지 않았습니다.
외부 표시 데이터가 없으면 현재 실제로 적용되는 체력·공격력 증가량을 보여줍니다.
기존 규칙은 침식 단계마다 몬스터 체력 +20%, 공격력 +10%입니다.

클로드가 새 효과를 구현한 뒤 서버에서 아래 메서드에 적용된 효과와 수치를 전달하면 됩니다.

```lua
_EndlessBurstLogic:SetHudModifiers("swarm:30|onslaught:30|curse:-50")
```

이 메서드는 표시 데이터만 받습니다. 실제 효과 계산도 같은 값으로 별도 적용해야 합니다.

| 키 | 한국어 이름 | 수치 의미 |
|---|---|---|
| fortitude | 강인 | 몬스터 체력 증가율 |
| frenzy | 광폭 | 몬스터 공격력 증가율 |
| haste | 질주 | 몬스터 이동속도 증가율 |
| swarm | 범람 | 몬스터 수 증가율 |
| onslaught | 맹공 | 몬스터 공격속도 증가율 |
| curse | 저주 | 플레이어 회복량 변화율, 감소는 음수 |

최대 3개, 중복 키·알 수 없는 키는 제외합니다. 소수 수치도 지원합니다.
빈 문자열은 현재 체력·공격력 표시로 돌아갑니다. 새 런에서 데이터가 초기화됩니다.

## 게임 파일

- `G:/Maple_Story_Deck/RootDesk/MyDesk/Effects/EndlessBurstLogic.mlua`

- `G:/Maple_Story_Deck/RootDesk/MyDesk/Localization/GameText.csv`

UI 파일은 UIBuilder로 수정했습니다. `resources.json`은 게임에 업로드한 각 PNG의 RUID입니다.
`prompts.json`은 내장 이미지 생성 도구로 사용한 최종 프롬프트와 승인된 원본 경로입니다.

## 확인 자료

`hud-current-effects.png`는 현재 실제 체력·공격력 증가 표시입니다.
`hud-1-effects.png`, `hud-2-effects.png`, `hud-3-effects.png`, `hud-tooltip.png`는 메이커 실제 화면에서 표시 데이터만 교체해 촬영한 예시입니다.
화면에 보이는 범람·맹공·저주는 새 전투 효과가 적용되었다는 뜻이 아닙니다.

검증은 `verification.json`과 빌드·런타임 로그에 저장합니다.
버튼 이벤트 연결은 엔진의 `ButtonClickEvent` 전달로 확인하며, OS 마우스나 실제 모바일 기기 터치 검증은 포함하지 않습니다.

검증 완료: 빌드 오류 0개, 런타임 오류 0개, 1개·2개·3개 레이아웃과 버튼 이벤트·툴팁·번역·일시정지 숨김·런 초기화 확인.
