# 에피1 무제한 모드: 이계 침식 시안

브랜치: `codex/endless-rupture-burst`

에피1 무제한 모드의 기존 10분 클리어 뒤에 침식이 시작된다. 클리어 배너가 끝난 뒤 첫 침식이 발동하고, 20초 연출 후 처치 충전 상태로 전환된다. 이후 100마리를 처치하면 다음 침식 단계로 올라간다. 연출 도중의 처치 수는 다음 충전에 쌓이지 않는다. 고정 초 단위로 자동 증가하는 방식은 아니다.

침식 단계마다 몬스터의 기존 체력이 20%p, 공격력이 10%p씩 추가된다. 1단계는 체력 1.2배·공격력 1.1배, 5단계는 2배·1.5배다. 기존 시간 경과 강화와 별도로 곱해지며, 20초 연출이 끝나도 몬스터 강화는 유지된다. 이미 나온 몬스터는 남은 체력 비율을 유지하면서 강화되고 새 몬스터도 즉시 반영된다. 퀘스트용 비전투 오브젝트·이벤트 칠면조 등은 체력 강화에서 제외한다. 사망 후 이어하기는 같은 단계가 유지되고, 새 판·로비 초기화·제외 모드에서는 해제된다. 플레이어 공격력·쿨타임은 변경하지 않는다.

기존 맵 배경을 유지하고 단계가 오를수록 보라색이 화면 중앙으로 차오른다. 마스크는 10단계까지 커지며 이후에도 중앙 시야는 보존한다. 몬스터 강화 단계는 11단계 이후에도 계속 증가한다. 침식 도착 시 보라색 빛·충격파를 재생한다. 이 게임은 기본 아바타를 숨기는 자동 전투이므로 연출은 실제 전투 영역에 배치했다. 상태판은 클릭을 막지 않으며 기존 HUD보다 아래에 표시한다.

## 범위와 조정

- 에피1 무제한 모드에만 적용한다. 타임어택과 다른 에피소드에는 적용하지 않는다.
- `EndlessBurstLogic.Enabled`로 전체 기능을 끌 수 있다.
- `BurstSeconds=20`(침식 도착 연출), `KillsPerBurst=100`, `MonsterHpPerLevel=0.2`, `MonsterAttackPerLevel=0.1`, `MaxVisualStage=10`를 같은 스크립트에서 조정할 수 있다.
- 맵·몬스터·기존 배경 UID·랭킹·보상 규칙은 변경하지 않았다.
- 한국어·영어·중문 번체·중문 간체·일본어·스페인어 문구를 기존 번역표에 추가했다.

## 확인

실제 PC 메이커의 서버 실행과 실제 몬스터 모델로 클리어 전 제외, 클리어 후 1단계 진입, 몬스터 체력 1.2배·공격력 1.1배, 기존 몬스터의 체력 비율 유지(50/100 → 60/120 → 70/140), 중복 배율 방지, 새 몬스터 강화, 플레이어 수치 불변, 20초 연출 후 강화 유지, 일시정지·안전지대, 99마리 대기/100마리 단계 증가, 6단계 이후 강화 지속, 새 판 초기화, 타임어택·다른 에피소드 제외를 검증했다.

밝은 헤네시스(map04)에서 1·3·5단계의 보라색 확산과 5단계 연출 종료 후 충전 표시를 비교했다. 숲에서 헤네시스로 이동한 뒤에도 상태가 유지됐다. 미리보기는 메이커의 임시 실행 상태에서 기존 클리어 진입점을 호출했으며, 생존 시간을 10분으로 앞당기거나 종이조각·해금·보상을 지급하는 테스트 코드는 제품 파일에 넣지 않았다. 모바일 실기기 성능은 이번 검증 범위에 포함하지 않는다.

## 기존 작업 보존

작업 시작 시 `develop`에 크리에이터 페스티벌 관련 수정과 TitleGroup UI 수정이 남아 있었다. 실험 브랜치에는 새 기능 파일과 몬스터 강화에 필요한 변경만 커밋하며 기존 크리에이터 페스티벌 수정은 별도로 남긴다. 초기 시안의 플레이어 보너스와 해당 번역 문구는 제거했다.


## 10단계 화면 확장

6단계부터 10단계까지 추가 마스크를 등록했다. 1단계부터 5단계까지의 모습과 전투 강화 수치는 유지하고, 6단계 이후에도 보라색 영역이 계속 중앙으로 확산되도록 했다. 10단계에서는 중앙의 작은 투명 영역만 남으며, 화면을 완전히 불투명하게 가리지는 않는다.
