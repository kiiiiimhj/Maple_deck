# 뚠호 장비 프레임 수정 v6

귀 뒤 망토 깃의 금색 끝과 검은 외곽을 낮추고 둥글게 정리했습니다. 대기·걷기·수면 네 컷씩을 포함해 실제 사용하는 동작에 반영했습니다. 원본 얼굴, 귀, 발, 꼬리, 효과와 재생 간격은 유지했습니다.

기존 장비 이미지를 이동·변형해서 얹는 방식 대신, 실제 원본 프레임에서 착용 영역을 직접 그렸습니다. 사용하는 13개 동작은 원본 프레임 참조 56개이며, 완전히 동일한 원본 홀드 9개를 제외한 47개 그림을 제작했습니다. 사용하지 않는 stand1/hang/roll은 새 장비를 그리지 않았습니다. 독립 장비 선택을 위한 마스크와 최종 몸+장비 통합 프레임을 모두 보관했습니다.

실제 메이커 검증: 사용 프레임 56개와 독립 장비 조합 8개를 화면 픽셀로 대조해 전부 일치했습니다. 돌보기 5종, 산책 발견, 수면, 허기·슬픔·분노·피로 상태, 인벤토리, 옷장, 첫 번째와 반복 낙하를 확인했습니다. 재생 감시 3,927회에서 몸/장비 프레임 분리 오류는 0개, 최종 빌드·실행 오류는 0개였습니다. 계정과 도토리는 테스트 전 상태로 복원했습니다.

게임 소스는 최신 파일에서 뚠호 그림 연결 표 세 곳만 수정했습니다. 기존 UI 배치·크기·코드, 장비 가격·옵션·아이콘, 다른 펫과 클로드의 수정은 유지했습니다. `applied.json`에 직전 백업과 변경 범위를 기록했습니다.

제작 방식: 내장 **image_gen**으로 원본 프레임의 착용 영역을 다듬고, 프레임별 직접 그린 경계 안에만 반영했습니다. 원본 몸체·효과의 보호 영역은 최종 448개 장비 조합에서 바뀐 픽셀이 0개입니다. 전체 프롬프트·입력·생성 결과 경로는 `generation-records/*.json`, 원본 입력은 `generation-inputs/`, 선택한 생성 결과는 `polished-sheets/`에 보관했습니다. `drawings/`에는 원본 몸체를 포함한 프레임별 편집 소스가 있습니다.

최종 연결: `final-manifest.json`. 원본과 최종 프레임 마스크만으로 재구성한 80개 게임 리소스는 모두 원본 SHA와 일치했습니다. 검증 자료는 `runtime/`, 몸체 보호 증명은 `native-body-protection-proof.json`에 있습니다.
