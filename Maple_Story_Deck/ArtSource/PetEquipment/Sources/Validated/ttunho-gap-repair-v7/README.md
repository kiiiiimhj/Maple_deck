# 뚠호 연결부 빈틈 수정 v7

승인한 v6 그림에서 두 군데만 보완했습니다.

- 대기·산책·씻기·휴식/앉기의 머리와 망토 사이에 빠진 안쪽 천을 메웠습니다.
- 산책 네 컷의 모자와 귀 사이에 빠진 연결부를 메웠습니다.

기존 장비의 칠해진 픽셀은 바꾸지 않고, 각 원본 프레임의 해당 연결부에만 안쪽 천을 추가했습니다. 원래 귀가 앞에 보이는 순서는 유지했습니다. 나머지 동작의 그림, 표정·발·꼬리·목걸이, 금색 테두리, 재생 속도, UI 위치·크기, 가격·옵션·아이콘은 유지했습니다.

[빈틈 전후 확대](previews/gap-comparison.png) · [걷기](previews/move.gif) · [씻기](previews/chat.gif) · [휴식](previews/rest.gif)

제작 방식: 기존 프레임별 SVG와 픽셀 원본의 직접 보수입니다. 이번 수정에는 새 이미지 생성이나 전체 그림 재생성을 사용하지 않았습니다. v6의 내장 image_gen 제작 기록은 프로젝트의 이전 버전 원본에 보관되어 있습니다. 변경 위치와 픽셀은 `gap-repair-proof.json`, 최종 그림의 차이는 `visible-diff-proof.json`에 있습니다. `drawings/`와 `polished-frame-paint/`가 수정된 편집 원본입니다.

최신 게임 파일에서 뚠호 통합 그림과 낙하 그림 연결 두 곳만 바꾸었습니다. 그 외 코드는 바꾸지 않았습니다. 실제 메이커 확인은 `runtime/`, 최종 연결은 `final-manifest.json`에 보관했습니다. 원본과 최종 프레임 마스크로 재구성한 80개 리소스는 모두 SHA가 일치했습니다.
