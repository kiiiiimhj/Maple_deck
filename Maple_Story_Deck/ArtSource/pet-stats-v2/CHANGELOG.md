# 펫 능력치 변경 — 2026-10-12

- 인벤토리 능력치 버튼과 행 디자인을 재사용하고, 펫 능력치 창을 버튼 아래 8px 간격으로 배치.
- 총 4줄: 종별 고정 고유 능력치 1줄 + Lv.3/6/9에 열리는 잠금 3줄.
- 추가 옵션 종류만 악세사리와 같은 5종에서 무작위 선정. 선택된 종류는 저장 후 유지하며, 각 줄은 독립적으로 추첨하므로 중복 종류도 가능.
- 수치는 고정. 해금 시 공격력/치명타 확률/치명타 피해/최대 체력/스킬 쿨타임 감소 순서로 1%/1%/2%/2%/0.5%, 이후 레벨마다 0.1/0.1/0.2/0.2/0.05%p 증가.
- 구리의 대미지, 뚱땅의 치명타 확률은 기존 고유 능력치 성장 곡선 유지.
- 기존 보유 펫 저장 데이터는 진행도 유지하며 누락된 해금 옵션만 한 번 생성.
- 장착 펫의 옵션을 캐릭터 능력치와 전투 시작 시 반영. 펫 쿨타임 옵션은 스킬에 적용.
- 펫 이미지, 프레임, 픽셀 정렬과 돌봄 동작은 변경하지 않음.
