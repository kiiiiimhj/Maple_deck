# 글레이셜 스윙

사용자가 선택한 최종 제작 방식은 **원본 프레임의 코드 색상 변환**이다. 이미지 생성으로 새로 그린 시안은 적용하지 않는다.

- 원본의 주 연출 9프레임, 보조 연출 6프레임, 타격 5프레임을 그대로 사용한다.
- 프레임별 픽셀 크기·모양·투명 영역·알파 채널을 유지한다. 알파는 각 프레임의 모든 픽셀이 원본과 일치한다.
- 원본 HLS 명도와 무채색 발광을 유지하고 따뜻한 색 성분을 차가운 청색으로 변환한다. 흐릿한 잔상은 낮은 채도로 변환해 원본 번짐이 딱딱한 파란 경계로 변하지 않게 한다.
- `compare-frames-4-5.png`: 왼쪽 원본, 오른쪽 최종 색상 변환본.
- `alpha-verification.json`: 20프레임의 원본 알파 일치 검사와 해시.
- `frame-metadata.json`: 원본 프레임별 시간·크기·기준점.
- `uploaded.json`: 등록된 프레임 RUID. 이미지 밖에 있던 기준점 두 곳은 재생 위치에서 차이를 보정한다.
- 아이콘은 기존 32×32 해머 아이콘의 색상 변환본이다.

## 게임 규칙

- 조합: 디바인 스윙 Lv.5 + 웨폰 액셀레이션 보유 + 실드 마스터리 보유.
- 디바인 스윙 슬롯을 승계하며 볼케닉 스윙과 글레이셜 스윙 중 하나로 강화된다.
- 레벨별 기본 대미지: 260 / 280 / 310, 기본 쿨타임 4초.
- 볼케닉 스윙과 같은 크기·타격 시점의 해머 광역 2곳. 두 범위가 겹쳐도 몬스터당 한 번 타격한다.
- 100% 확률로 2초 슬로우. 기존 몬스터 규칙에 따라 이동속도가 50% 감소한다.
- 기존 시전음과 검색한 얼음 파쇄 타격음 사용. 효과음 음량 설정을 따른다.
- 카드 260 / 영구 스킬 인덱스 150. 6개 언어 이름·설명과 조합식, 목록·확률표에 연결한다.

최종 메이커 검증과 저장 결과는 `verification.json`, `manifest.json`, `saved-ui.json`에 기록한다.
