# 발로르: 홀리 크리티컬 / 강화 드라이브

실제 게임 적용 경로: `G:/Maple_Story_Deck`

- 홀리 크리티컬(263): 패시브, 크리티컬 피해 +10/20/30/40/50%. 기존 패시브와 같은 영구 강화 보너스 +3/6/9%.
- 볼케닉 드라이브(264): 홀리 드라이브 Lv5 + 홀리 크리티컬 + 웨폰 액셀레이션. 피해 220/240/270, 쿨타임 5초, 망치 2개. 화상 2초, 1초마다 25% 피해. 슬로우 대상 20% 추가타.
- 클레이셜 드라이브(265): 홀리 드라이브 Lv5 + 홀리 차지 + 홀리 크리티컬. 피해 220/240/270, 쿨타임 5/5/6초, 망치 2/2/3개. 슬로우 2초. 화상 대상 20% 추가타.
- 관통: 투사체마다 첫 대상 + 추가 최대 4마리. 첫 대상 100%, 추가 대상 60%. 두 분기는 같은 기본 슬롯을 이어받으며 동시에 배울 수 없음.

## 그림과 프레임

새 잔상과 패시브 아이콘은 **내장 ImageGen**으로 제작했다. 최종 프롬프트와 참고 이미지 목록은 [prompts.json](prompts.json)에 있다.

원본 홀리 드라이브의 모든 프레임을 확인하고 사용했다: 망치 8장, 발사 섬광 7장, 추진 효과 11장, 뒤쪽 조각 11장, 명중 7장. 투명한 빈 프레임도 원래 순서와 시간을 유지한다.

두 속성의 원본 프레임은 사용자가 허용한 코드 색상 변환을 적용했다. 그림 크기·알파·프레임 시간·원본 피벗은 유지하고, 밖으로 나간 피벗은 게임 좌표로 보정한다. 실제 그림이 있는 84장의 알파가 원본과 바이트 단위로 일치함을 [alpha-verification.json](alpha-verification.json)에 기록했다.

회전 잔상은 별도 투명 레이어다. 손잡이 끝을 중심으로 망치와 함께 회전하며, 얼음은 푸른 빛·서리·얼음 조각, 용암은 붉은 불꽃으로 표현했다. 추진 연출은 원본 전체 프레임의 소멸 흐름을 지키고 뒤로 흩어지는 조각을 추가했다.

## 확인

[verification.json](verification.json)에 메이커에서 수행한 실제 검증 결과가 있다. 조합 조건, 슬롯 승계, 레벨 제한, 치명타 진입점 3종, 양방향 관통, 속성 추가타, 2회 화상, 일시정지, 초기화·존 이동·몬스터 재사용, 프레임·피벗·아이콘·조합 도감·6개 언어 표시를 확인했다.
