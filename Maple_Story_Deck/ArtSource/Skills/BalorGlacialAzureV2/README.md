- 사용자 지정 글레이셜 기본 대미지: **280 / 300 / 320**. 쿨타임 4초, 광역 2곳, 슬로우 2초 유지.
- 볼케닉 기본 대미지는 260 / 280 / 310으로 유지.
- 원본 20프레임의 픽셀 크기·알파 채널·기준점·프레임 시간 유지.
- 원본 픽셀 색상 변환 방식 유지. 짙은 청색을 밝은 하늘색으로 조정하고 어두운 면의 명도를 높였다.
- `compare-frames-4-5.png`: 왼쪽 이전 색상, 오른쪽 수정 색상.
- `alpha-verification.json`: 원본 프레임 알파가 픽셀마다 동일한지 검사한 결과.

## 연출 위치

주 충돌 프레임은 461×221, 아래쪽 기준 pivot(327,21)이다. 그림 중심이 앵커보다 89.5px 위에 있으므로 앵커의 Y 보정은 `-0.895 × scale`이어야 한다. 기존 양수 보정을 음수로 수정했다. 보조 연출도 같은 이유로 `-0.43 × scale`로 수정했다.

볼케닉 스윙과 글레이셜 스윙 모두 실제 연출 중심이 광역 판정 중심, 즉 타겟 몸 높이와 일치하도록 맞췄다. 몬스터의 깊이 크기에 따라 동일한 비율로 보정한다.

`uploaded.json`은 새 프레임 및 32px 아이콘 RUID를 담는다. `verification.json`은 메이커에서 측정한 위치 일치·피해·클라이언트 렌더 색상과 번역 확인 결과를 담는다.
