# 뚱땅 전용 장비: 원본 픽셀에 맞춘 버전 8

이번에 별도로 다시 그린 것은 모자, 조끼, 목걸이뿐입니다. 원본 뚱땅 이미지 76개는 수정하지 않았습니다.

- 모자, 옷, 목걸이는 각각 장착·해제할 수 있는 독립 이미지입니다.
- 서 있기, 먹기, 잠자기, 탐색, 웅크리기, 공중 점프용 장비를 별도로 그렸습니다.
- 모든 장비를 원본 128 × 128 픽셀 좌표에 맞추고 공통 색상으로 정리했습니다.
- 원본 눈/얼굴을 보존하며 귀와 앞발은 장비 앞에 보이도록 정리했습니다.
- 수면 중 목걸이는 펜던트 없이 갈색 끈만 남습니다.
- 획득 방식은 기존대로 메이커 시험 장착만 지원합니다.
- 능력치와 원본 펫 애니메이션 타이밍은 변경하지 않았습니다.
