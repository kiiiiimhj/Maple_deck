공격 모션 뒤에 탄이 출발하고, 화면 중앙 부근으로 커지며 이동하고, 화면 접촉 때 대미지가 한 번 적용됩니다. 일시정지는 비행·착탄·대미지를 함께 정지합니다. 발사 전 몬스터 사망·변신·재사용은 취소하고, 이미 발사된 탄은 사망 뒤에도 날아갑니다. 맵 이동·새 게임·다시하기 때 이전 탄을 정리합니다.

메이커 검증: 아래 26종의 실제 OnReachPlayer 경로, 이미지 로드, 비행·착탄, 대미지 시점 및 중복 방지, 일시정지, 정리 처리가 통과했습니다. 사망·변신·엔티티 재사용·맵 이동·새 게임 취소와 발사 후 사망도 확인했습니다. 설원 예티·다크 예티와 루디브리엄 바이킹·G.팬텀워치는 실제 AI 공격과 맵 배경에서 별도로 확인했습니다. 모바일 실기기에서는 아직 확인하지 않았습니다.
