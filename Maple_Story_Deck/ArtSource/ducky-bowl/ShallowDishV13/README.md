# 더키 밥그릇 수정

기존의 깊은 그릇과 높이 쌓인 사료가 입과 앞발을 가리던 부분을 얕은 밥그릇으로 교체했다. 이전 화면 기준 그릇 중심은 왼쪽으로 26픽셀 이동했으며, 그릇 바닥은 앞발 바닥 높이에 유지한다. 새 도트는 32×10픽셀이고, 투명 128픽셀 캔버스의 (28,108)–(60,118)에 위치한다. 몸통 원본·먹기 동작·장비 이미지는 변경하지 않았다.

제작 방식은 내장 image_gen 편집 도구이며 전체 생성 문구는 imagegen-prompt.txt, 생성 원본은 bowl-generated-source.png, 게임 적용 파일은 food-bowl-v13.png다. 도트 크기에 맞춰 최근접 방식으로 내보내고 Point 필터로 등록했다.

메이커에서 무장비·기존 장비·새 장비의 정상 먹기 동작을 각각 재생하여 8프레임 전체를 관찰했다. 서로 다른 4자세를 각 장비 상태에서 별도로 확인했다. 먹기 중 바닥 좌표 고정, 끝난 뒤 숨김, 다른 펫에서 숨김을 확인했다. 코드 변경 범위는 밥그릇 리소스와 배치 메서드뿐이며 기존 구리·부기 및 뚱땅 수정은 유지한다.
