# 펫 하우스 가이드

펫 하우스 왼쪽 위 안내 버튼에서 네 단계 그림 안내를 엽니다.
펫 돌봄 → 친밀도 보상 → 모험 점수와 성장석 → 펫과 함께 모험 순서로 나타납니다.
화면을 누르면 안내를 닫고 펫 하우스로 돌아갑니다. 다시 열면 첫 단계부터 재생됩니다.

보상 그림의 강화주문서는 게임에서 사용 중인 실제 아이콘입니다.
성장석 그림은 전투 화면에 성장석을 붙였으며 그림 안의 화살표를 제거했습니다.
단계 사이 연결 화살표는 사용자가 제공한 곡선 모양으로 새로 그려 적용했습니다.
문구는 한·영·중문 간체/번체·일본어로 제공합니다.

실제 메이커에서 안내 버튼 클릭, 일곱 부분의 등장 순서, 전체 그림과 주문서 로드,
그림을 눌러 닫기, 재열기, 하우스 종료, 작은 화면 배치, 미보유 펫에서도 안내 열기를 검증했습니다.
검증 중 임시 계정 상태는 원본으로 복구했습니다. 최종 실행 및 빌드 오류는 0입니다.

펫 보상·성장·스킬·저장 로직과 기존 레이드 및 로비 소스는 그대로입니다.
최종 이미지 5개는 assets/에, 실제 화면은 pet-tutorial-applied.png에 보관합니다.
이미지는 built-in image_gen으로 생성했으며 최종 프롬프트는 generation-record.json에 기록했습니다.
