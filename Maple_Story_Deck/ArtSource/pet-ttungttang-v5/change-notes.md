# 뚱땅 발·꼬리 보완 v5

- 산책: 다리 네 개가 반대쪽 대각선 쌍으로 번갈아 디딥니다. 발을 통째로 잘라 이동하던 방식의 발목 중복과 빈 틈을 수정했습니다. 발 들기는 원본 크기 기준 1~2픽셀입니다.
- 기본 자세: 꼬리 뿌리를 고정하고 끝부분만 흔듭니다. 반복 끝과 눈 깜박임 구간에서 꼬리 위상이 튀던 순서를 연속된 주기로 바꿨습니다.
- 먹이: 고개를 숙이는 그림과 꼬리 그림을 원본에서 따로 분리했습니다. 꼬리에 고개 그림 조각이 끼어 잘린 것처럼 보이는 문제를 수정했습니다.
- 털색·그림체는 기존 그림의 픽셀을 재사용했습니다. 목욕·주사·잠자기·반응 그림은 v4와 동일합니다.

검증: 수정한 세 동작의 36프레임에서 분리된 조각과 연결부 투명 틈이 없습니다. 메이커 실제 먹이·산책 버튼, 동작 종료, 기본 눈 깜박임과 인벤토리 공유 연결을 확인했습니다. 실제 기본 자세 화면 네 장에서 움직이는 꼬리 이외의 얼굴·몸·발 차이는 0픽셀입니다.

검증 도중 인벤토리 확인용 외부 스크립트에서 펫하우스 전용 함수를 한 번 호출한 오류가 있었고, 실제 인벤토리 함수로 고쳐 확인했습니다. 게임 소스의 빌드·실행 오류는 없습니다. 펫하우스는 뚱땅 임시 미리보기를 열어 두었으며 돌봄 버튼 다섯 개를 사용할 수 있습니다. 계정 영구 저장은 변경하지 않았습니다.
