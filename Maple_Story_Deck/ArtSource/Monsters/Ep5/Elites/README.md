# 아랫마을 엘리트 전용 리소스

에피소드5 첫 맵의 존190~199에서만 전용 로스터4종을 사용한다. 기존 엘리트 출현 주기·가방 순환·체력·보상 공식을 유지한다.

| 이름 | 전용 폴더 | 행동 |
|---|---|---|
| 청안 백호 | WhiteTiger | 파란 눈·흰 털, 발판 범위 안에서 지그재그 근접 |
| 달그림자 토끼 | MoonRabbit | 보랏빛 털·초승달, 도약 후 근접 공격 |
| 청령 여우 | SpiritFox | 흰 털·청록 꼬리, 여우불 원거리 공격 |
| 금날개 제비 | GoldSwallow | 금빛 날개·이마 깃털, 자유 비행 |

- 엘리트마다30장, 여우불 비행6장·착탄6장, 총132장의 별도 리소스.
- 모든 프레임112×112 RGBA, Point/Clamp, pivot=(0.5,0.3). 발판 기준선78픽셀. 가까운 피격·사망 전환을 포함해 단일 렌더러로 재생한다.
- 각 폴더 spritesheet.png는 실제 적용 프레임을 다시 포장한 최종본이다. 적용하지 않은 오류 시안은 이 폴더에 넣지 않았다.
- 백호 공격은 앞발과 지지 다리를 분리해 수정했다. 토끼 공격은 대기 자세와 머리 비율이 맞는6장으로 교체했다. 방망이 하나를 들어 휘두르고 복귀한다.
- 토끼는 비균일 스케일 변형 대신 그려진 웅크림·도약·착지 프레임과 실제 포물선을 함께 쓴다.
- 여우불은0.36초 준비 후0.85초 비행하며 실제 도착 시점에만 타격한다. 기존 투사체 취소·맵 이동·수명 처리를 공유한다.
- 이미지 생성: Codex 내장 image_gen. 제작 프롬프트: generation-prompts.json.
- 메이커 검증: verification/actual-verification.json 및 native-spawn-verification.json. 전체 엘리트120프레임, 투사체6·착탄6, 피격/공격 복귀, 점프 착지·지그재그·비행, 실제 엘리트 스포너4종 출현을 확인했다.

게임 연결: RootDesk/MyDesk/GameManager.mlua, MonsterAI.mlua, MonsterSpawner.mlua, Combat/MonsterProjectileFx.mlua.
