# 맵 3~5 전용 엘리트 5종

에피소드5 존210~239에서 공통으로 사용한다. 맵1·2(190~209)의 기존4종은 유지한다. 원형은 맵4·5 몬스터이며 맵3 사물 도깨비7종은 사용하지 않는다.

| 이름 | 원형 | 행동 |
|---|---|---|
| 흑철 왕도깨비 | 파란 왕도깨비 | 지그재그 근접, 철가면·붉은 갈기·철테 방망이 |
| 청옥 왕도깨비 | 초록 왕도깨비 | 점프 근접, 청옥 가면·흰 갈기·옥 방망이 |
| 자안 야광귀 | 야광귀 | 지상 원거리, 보라 구슬·전용 착탄 |
| 백련 선비귀신 | 선비귀신 | 비행, 부채 휘두르기·부채바람 타격 |
| 홍련 대감귀신 | 대감귀신 | 추가 돌진형, 붉은 관복·큰 주먹 |

내장 image_gen으로 5종의 동작과 효과를 제작했다. 애니메이션 몸체150프레임은256×256, 투사체/효과18프레임은192×192이다. 작은32/64픽셀 중간 파일을 거치지 않고 원본에서 추출했다. 몸체는 지상 발끝192픽셀, 비행 중심(128,128), pivot(.5,.25)를 사용한다. 효과는 중심(96,96), pivot(.5,.5)를 사용한다. 적용 필터는 Point/Clamp이다. 몸체의 투명 여백을 늘려 큰 공격 궤적을 보존하고, 선택된 각 시트 안에서는 같은 배율로 추출했다.

공격 궤적이 붙어 있던 시안은 별도 공격 시트로 교체했고, 청옥 점프는 별도 그려진 웅크림·도약·착지 시트를 사용한다. 홍련 대감귀신의 맞닿은 사망 포즈도 별도 사망 시트로 교체했다. 신체/무기/눈 디자인을 보존했다. 경계가 잘린 일부 대기/걷기 포즈는 정상적인 같은 동작의 포즈로 대체했다. 최종 적용 모습은 각 폴더 spritesheet.png/contact-sheet.png 및 실제 화면에 있다. 원본시트에서 교체한 공격·사망 행은 재사용하지 않는다. 선택된 수리 원본은 해당 폴더의 attack-master.png, move-master.png, die-master.png에 보관한다.

새 엘리트는 그림을 비균일하게 찌그러뜨리는 공격 동작을 쓰지 않는다. 지그재그·점프·비행·돌진의 실제 위치 이동과 원거리 투사체를 공유 엔진에 연결한다. 이전 일반종에서 공격2/소환 정보가 섞이지 않도록 새5종에 한해 초기화한다. 4↔5 로스터 이동 때 종 추첨 가방만 갱신하고 보상·출현 간격은 유지한다.

실제 메이커에서 새5종 및 기존4종 라우팅, 4↔5 추첨, 전체 프레임 재생·공격/피격 복귀·공백/잘못된 프레임/비율 변형, 다섯 행동과 양방향 투사체·착탄을 확인했다. 검증은 피해0의 시각 경로로 진행했고 계정진행/가방/체력 및 테스트 개체를 복구했다. 빌드/새 실행 오류0. 상세증거는 actual-verification.json, visual-verification.json, movement-verification.json, projectile-verification.json.

전체 제작 프롬프트와 선택된 수리 시트는 generation-prompts.json. 게임 연결은 GameManager.mlua, MonsterAI.mlua, MonsterSpawner.mlua, Combat/MonsterProjectileFx.mlua.
