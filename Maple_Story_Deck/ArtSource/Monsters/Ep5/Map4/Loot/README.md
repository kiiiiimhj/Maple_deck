# ep5 map4 일반 몬스터 잡템

빈 드롭 항목이 있던 일반 몬스터8종에 전용 잡템8종을 추가했다. 깨비 1·2페이즈 모두 같은 아이템을 조회하며, 1페이즈 변신 중에는 지급하지 않는다. 기존 사망/변신 처리와 드롭 확률은 유지한다.

| 몬스터 | 잡템 | 점수/환전가 |
|---|---|---:|
| 깨비 | 깨비의 불씨 | 13 |
| 파란 왕도깨비 | 파란 도깨비의 가면 조각 | 14 |
| 초록 왕도깨비 | 초록 도깨비의 짚끈 | 14 |
| 노란 왕도깨비 | 노란 도깨비의 방망이 조각 | 14 |
| 도령귀신 | 도령귀신의 머리끈 | 13 |
| 양반귀신 | 양반귀신의 낡은 갓 | 14 |
| 처녀귀신 | 처녀귀신의 낡은 빗 | 13 |
| 대감귀신 | 대감귀신의 옥패 | 14 |

아이콘은 built-in image_gen으로 제작했다. 전체 프롬프트는 generation-prompts.json, 원화는 masters/, 실제 등록한 PNG는 icons/의 고해상도 원화 재추출본이다. 확대 미리보기는 loot-icons-preview.png. 현재 아이콘은 원화 알파와 색을 보존한 재추출본이며 Point필터와 중앙 피벗을 사용한다.

드롭표·인벤토리 획득 순서·점수·환전 목록·랜덤 잡템 풀과 한국어/영어/중문 번체/간체/일본어 이름을 연결했다. 실제 메이커에서8종의 드롭 조회, 아이콘 로드, 지상/공중 낙하·수집, 가방 표시와 점수를 확인했다. 깨비의 변신과 2페이즈 잡템 조회도 확인했다. 테스트 수량은 원래대로 복구했다. 환전 지급/초기화는 격리된 Lua 검증으로 확인해 실제 계정 코인을 변경하지 않았다.

상세 결과: loot-verification.json, catalog-verification.json. 실제 가방 화면: actual-loot-inventory.png.
