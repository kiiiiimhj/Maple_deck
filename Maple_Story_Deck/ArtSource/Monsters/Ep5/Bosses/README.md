# 에피소드5 보스 3종

에피소드5(존190~239)의 전용 보스 순환 목록이다. 에피소드1~4의 기존 보스는 그대로 유지한다.

|보스|동작과 패턴|
|---|---|
|금강 대왕깨비|도깨비 왕 원형. 피격당 크기+10%, 최대+80%; 공속+5%, 최대+60%. 크게 방망이를 내려친다. 최대 공속에서도 전체 공격 프레임을 보존한다.|
|창천 양반귀신|양반귀신 원형. 비행·원거리 부채 구슬 공격. 첫 소환 후 24초 간격으로 도령귀신 3마리 소환. 소환 중 일반 공격을 겹치지 않고, 죽거나 교체된 소유자의 예약 소환을 취소한다. 부하는 보스에 연결된다.|
|경인년 호걸|원형을 바탕으로 보스 전용 외형과 36프레임을 새로 제작했다. 대기·이동·점프·공격·피격·사망을 직접 그렸으며 원본 사운드는 유지한다. 호돌이 호위4마리가 좌우2마리씩 등장하고 존 이동을 함께 한다.|

세 보스의 원화와 전용 투사체는 내장 image_gen으로 제작했다. 최종 프롬프트는 generation-prompts.json. 몸체102프레임 중 금강·창천66프레임은320×320(지상 발256픽셀, 비행 중심160픽셀), 새 호걸36프레임은448×448(발358.4픽셀)이며 모두pivot(.5,.2)다. 호걸의 투명 여백만 늘려 본체 약160픽셀과 세계 크기는 유지했다. 효과12프레임256×256/pivot(.5,.5). 원본 해상도에서 바로 추출했으며 작은32/64픽셀 중간 이미지를 거치지 않는다. Point/Clamp. 큰 공격 궤적은 별도 공격 원본으로 그려 잘림을 방지했다. master.png의 교체된 원래 공격 행은 게임에서 사용하지 않는다.

호걸 v1에서 기록한 원본 애니메이션 치수·시간은 과거 참고 자료(native-hogeol-runtime-metrics.json)이다. 현행 호걸 v2는 새로 그린6종 동작36프레임을 사용하며 원본 skill1 재생은 사용하지 않는다. 새 점프6프레임은 반복 없이 재생하고 기존 비율 변형 없는 점프 궤적에 연결한다. 발톱 공격 궤적이 새 공격 그림에 포함되어 옛 원본 착탄 효과는 제거했다. 일반 몬스터 외형이 보스의 크기나 피격음을 바꾸지 않도록 새 보스에 명시적으로 지정했다. 새 그림3종의 체력바와 머리 위 표식은 투명 캔버스 여백을 제외한 실제 그림 경계에 맞춘다(boss-visible-bounds.json).

기존 v1의 실제 메이커 검증 기록: 에피소드 라우팅, 에피5 다섯 맵에서 보스 초기 크기 일치, 전체 신규 프레임 재생 및 공백/잘못된 프레임/비율 변형, 성장 상한과 공격 간격, 호걸 점프13프레임·착지·반복 없음, 양방향 투사체/착탄, 공중 소환3마리와 예약 소환 취소, 호위4마리 및 존 이동/체력 유지. 테스트는 계정 진행과 인벤토리를 보존하고 테스트 개체를 제거한 후 원래 편집 맵으로 복구한다. 보상에 영향을 주는 실제 사망 처리는 실행하지 않았고, 연결된 보스 사망 시 자식 정리 분기는 오프라인 Lua 호출 검사로 확인했다(offline-linked-cleanup.json). 이 문단의 과거 v1 상세 결과는 기존 actual-verification.json이다. 새 호걸 v2의 동작36프레임·점프·호위·체력바 검증과 최종 소스 해시는 별도의 v2 검증 기록을 사용한다.

최종 화면 확인에서 창천 양반귀신의 큰 모자·체력바가 화면 밖으로 나가지 않도록 새 양반 보스만 비행 중심Y=-1.19, 상하 진폭=.04로 맞췄다. 좌우 비행과 공격·소환은 유지한다. 이 한정 보정 후 최고·최저 높이, 쫄병3마리의 실제 Sprite/alpha=1/Scale=.8/Enable과 화면을 별도로 검증했다(minion-visibility-verification.json, actual-summons-visible.png). 최초 전체 패턴 검증 소스 해시와 최종 높이 보정 전후 해시는 별도 기록하며 현재 최종 해시는 source-hashes.json에 있다.

연결 소스: GameManager.mlua, MonsterAI.mlua, MonsterSpawner.mlua, Combat/MonsterProjectileFx.mlua. 기존 성장/소환/호위 시스템을 재사용한다. 보상·상점·잡템은 이번 변경에 포함하지 않는다.

호걸 v2 변경은 GameManager의 세 번째 보스 정의·전용 프레임·실제 그림 경계에 한정한다. 앞의 두 보스 정의와 최신 창천 비행 높이 보정을 보존한다. 과거 native 프리뷰·측정 자료는 현행 적용 이미지와 구분하며, 옛 archive 스크립트로 새 정의와 검증을 덮어쓰지 않는다.

새 호걸 v2의 실제 재생 검증은 HogeolV2Verification/actual-verification.json, 현재 그림은 gyeongin-hogeol/contact.png 및 attack-preview.gif를 사용한다. 6종 전체 프레임·점프·호위4·존 이동·표식·복구 검증을 통과했다.
