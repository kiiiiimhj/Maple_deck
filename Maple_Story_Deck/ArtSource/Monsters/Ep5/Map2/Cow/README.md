# 소 — ep5_map2 돌진형

사용자가 제공한 소 원본 클립·효과음을 그대로 사용한다. 새로 그린 이미지나 변형 프레임은 없다.
현재 ep5_map2의 존4·6·8·10에 배치했다. 기존 map1 편성은 변경하지 않았다.

- 기본 배율0.85, 발판 안전 폭144px. 좁은 타일은 몸 크기에 따라 스폰 후보에서 제외된다.
- 약0.85초 준비→원본 달리기와 먼지→도달 시 제자리 점프 없이 들이받기→대기로 복귀.
- 대기17/이동10/피격1/사망7프레임. 실제 메이커에서35장 모두 관측했다.
- 사망은 메이커의 실제 프레임 지연 합계1.02초를 사용한다. CDN 미리보기의 균등 프레임 시간을 적용하지 않는다.
- 원본의 바닥 피벗을 유지하고, 모션마다 이미지 크기를 재계산하는 처리를 추가하지 않았다.
- 초기화 중에는 업데이트를 잠깐 멈춰, 준비 위치가0으로 잘못 저장되는 생성 순서 문제를 방지한다.

## 리소스

원본 RUID는 cow-definition.json, 프레임별 실제 RUID/크기/피벗/지연은 native-clips.json에 있다.
GIF/PNG는 CDN 미리보기 참고용이며 실제 적용 이미지를 대체하지 않는다.

## 실제 확인

35프레임 재생, 모션 전환 중 빈 표시0/가로세로 비율 차이0/고정 상태 배율 변화0을 확인했다.
소3마리와 기존 닭2종의 준비→달리기→도달→대기 복귀를 확인했다.
4개 존에서 고른12개 스폰 좌표가 실제 발판과 일치하며, 추가로 생성된 소의 실제 발 위치도 대조했다.
새 실행 오류0. actual-verification.json에 세부 결과와 적용 소스 식별값이 있다.
