# 에피소드5 map2 일반 몬스터

- 닭·흰 닭: 제공된 원본 애니메이션 사용. 짧은 준비 후 달려드는 돌진형.
- 누렁이: 금갈색 들개. 대기/이동/정면 물기/피격/사망 30프레임.
- 밤다람쥐·청설모: 각 30프레임, 도토리를 준비하고 던지는 원거리형.
- 참새·회색머리 참새: 무리 이미지 대신 한 마리씩 제작. 각 30프레임(비행12, 공격6, 피격6, 사망6), 일반 제비와 같은 배율1.4.
- 도토리: 회전6장, 껍질 파편 착탄6장. 루팡처럼 회전·포물선·접근 확대·잔상. 준비0.30초, 비행0.56초, 착탄0.42초.

새 그림은 내장 image_gen으로 제작했으며 전체 프롬프트는 generation-prompts.json에 보관했다.
각 캐릭터 폴더에 최종 원화, 프레임별 PNG, 실제 적용 아틀라스, 모션 미리보기가 있다.
원본 닭은 재업로드하지 않고 species-definitions.json의 기존 RUID를 사용한다.

## 픽셀과 전환

모든 새 프레임은112×112 동일 캔버스, pivot(0.5,0.3), Point/Clamp, 알파0/255를 사용한다.
추출 시 눈·몸통·바닥 기준을 맞췄고 보이는 픽셀의 잘림은162장 전부0이다.
개별 프레임의 외곽 크기에 맞춰 매번 확대하는 처리는 없다. 날개·다리의 포즈 변화는 원화에 그려져 있다.
가까이 다가오는 기존 게임 연출과 공격의 짧은 깊이 연출은 유지한다. 공격 시 가로·세로를 같은 비율로 움직이고 종료하면 원위치·원래 크기로 복귀한다.

## 존 배치

map2 존1~10은 내부 인덱스200~209이다. 앞쪽은 닭·누렁이 중심, 뒤쪽으로 갈수록 다람쥐·참새를 섞는다.
zone-rosters.json에 전체 구성, zone-info.json에 실제 저장된 맵의 위치와 지면 높이를 보관했다.
공중 발판은 실제 FootholdComponent와 몬스터 폭으로 스폰 안전 여유를 구한다.
map1 마지막 존199↔map2 첫 존200 이동을 연결했다.
