# 에피소드5 일반 몬스터 잡템

신규 동물8종에 잡템5종을 연결했다. 엘리트 전용 잡템은 추가하지 않았다. 기존 월묘·호돌이·호걸·삼미호·제비의 잡템도 누락 없이 유지했다.

| 잡템 | 드롭 몬스터 | 점수/환전가 |
|---|---|---:|
| 닭 깃털 | 닭, 흰 닭 | 11 |
| 참새 깃털 | 참새, 회색머리 참새 | 11 |
| 누렁이 목줄 | 누렁이 | 11 |
| 잘 여문 도토리 | 밤다람쥐, 청설모 | 11 |
| 소의 뿔 | 소 | 12 |

내장 image_gen으로 아이콘을 제작했다. 전체 프롬프트는 generation-prompts.json, 원화는 masters/, 실제 적용 파일은 현재 고해상도 원화 재추출본이며 QualityV3/quality-profile.json을 기준으로 한다. Point필터·중앙 피벗·투명 알파·잘리지 않은 여백을 확인했다.

## 연결 및 확인

- 몬스터별 드롭표, 가방 획득 순서, 게임오버 점수, 다시하기 환전, 미니무르 랜덤 잡템 풀에 모두 등록.
- 기존 언어표에 한국어·영어·중문 번체/간체·일본어 이름을 추가.
- 실제 메이커에서 일반 몬스터13종의 드롭 조회와 지급 경로, 새 아이콘5종의 드롭 연출·가방 표시·이름을 확인.
- 실제 수량은13개/잡템 종류10개, 점수146. 검증용 수량은 원래 상태로 복구.
- 격리된 Lua에서 획득 순서, 점수, 환전 지급/초기화, 랜덤 잡템 풀을 확인. 실제 계정에 환전 코인을 지급하지 않았다.
- 빌드 및 새 실행 오류0. actual-verification.json과 catalog-verification.json 참조.

## 2026-10-20 목줄·부적 두께 보강

누렁이 목줄과 깨비 부적은 그림 자체를 두툼하게 재제작했다. 현재 등록 파일은 투명 여백을 제거한 비율 유지 PNG이며, [두께 보강 기록](ThicknessV2/README.md)에 원화·적용본·프롬프트·실제 화면과 검증 기록이 있다.
