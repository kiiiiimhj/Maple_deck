# Balor entrance artwork v1

Generated with the built-in image generation tool, edit mode with three identity/style references. Transparent RGBA output. The original Balor front remains unchanged; these four frames extend the existing turning entrance.

Prompt: Production pixel-art four-frame turning spritesheet for a MapleStory-style entrance. Ref 1 is the exact Balor identity. Refs 2 and 3 are pose/style references only, not the orange-haired character identity. Preserve purple spiky hair, gold headband, pale face, blue/gold holy knight armor, gauntlets, boots, cape, and large black/purple/gold equipment on the back. Four equal cells in one row: quarter-front facing left, left profile, quarter-back, full back. Identical head size, height, baseline and scale. Crisp chunky hand-placed pixels, thin dark outline, clustered colors. No smooth vector, 3D, blur, attack effects, shadows, aura, text, or dividers. Generous transparent gaps and margins. Alpha transparent.

Packaging: extract the four cells on a common vertical baseline, trim horizontal empty space, and resize all to 80px height with nearest-neighbor sampling. No creative retouching after generation.
