# 펫 장비 구매창 v2

구매창 전용 배경과 버튼6종을 내장 image_gen으로 새로 그렸다. 최종 프롬프트는 generation-prompts.json, 생성 원본은 Sources/, 등록한7개 텍스처는 Textures/에 있다. 패널은 원화 비율을 유지해1000×720 캔버스에 맞췄으며, 버튼은 같은 비율로 축소했다. UI 스킨은 중심pivot(.5,.5), Bilinear/Clamp를 사용한다.

제목은 안쪽 목재 명패 중앙(0,234), 두 버튼은 하단 전용 영역(±166,-238)에 놓았다. 버튼252×68의 최저점은-272로 패널 외곽과88px 간격이며 실제 그림의 안쪽 선과도 겹치지 않는다. 가격은 다이아 아이콘과 숫자500만 표시한다. 가격 라벨과 보유 다이아는 숨기고 빈 문자열로 지웠다. 구매 가능한 경우 잔액을 설명하는 문구도 출력하지 않는다.

장비 아이콘30개는 원본48/50/64픽셀 RGBA를 조사했다. 원본 그림 잘림이나 중간 알파 손상은 없고, 이전190×174 UI의 비정수 확대가 큰 픽셀 계단을 만들었다. 원본파일은 수정하지 않고48→96,50→100,64→64의 정수배율로 표시한다. 상세 원본경로와alpha bounds는icon-metrics.json.

실제 메이커에서30종 이름·이미지·옵션·숫자 가격·숨김 항목·새 원화RUID·제목/버튼 안전영역·작은 아이콘·재오픈·취소를 확인했다. 잔액499/500/501 등의 표시 상태는 클라이언트 표시값만 바꿔 원복했고, 현재 실제 계정은 뚱땅 장비6개를 이미 보유하고 다른 펫은 미보유여서 구매 가능 분기와 이중클릭 요청 수는 격리된Lua 검증을 함께 사용했다. 기존 서버 구매와 다이아 차감/저장은 수정하지 않았으며 실제 구매는 테스트하지 않았다. 계정 지갑과펫 상태를보존하고map01편집모드로복원했다. Verification/actual-verification.json 및offline-verification.json 참조.

이번 수정 소스는RootDesk/MyDesk/Inventory/UI/UIInventory.mlua 하나다. 이전v1에서 추가된PetUI 닫기 연결은 유지한다. 현재 코드 해시는source-hashes.json. 실제 화면은Verification/actual-cap.png,actual-coat.png,actual-necklace.png이고 대표화면은purchase-preview.png다.
