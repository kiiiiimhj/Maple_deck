# 발로르 입장 — 사용자 선택 원본

사용자가 최종 선택한 2×2 원화 시트를 그대로 사용합니다. 이 버전에서 그림을 다시 생성하거나 형태를 수정하지 않았습니다. 정면은 제공된 발로르 PNG를 유지합니다.

게임 적용을 위한 프레임 분리, 73px 높이 최근접 이웃 축소, 발 위치 정렬만 수행했습니다. quarter-front.png, side.png, quarter-back.png, back.png가 선택 원화에서 추출한 4프레임입니다. preview.png는 확인용 확대본입니다.

이후 생성했던 해머 수정 시안은 사용하지 않습니다. 최종 리소스는 uploaded.json, 메이커 재생 확인은 verification.json에 기록합니다.
