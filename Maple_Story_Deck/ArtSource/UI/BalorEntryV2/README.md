# 발로르 입장 원화 v2

새 갑옷과 짙은 망토, 짧은 보라색 머리를 반영했습니다. 머리띠는 없으며 해머는 등에 고정되어 몸과 함께 돌아갑니다. 옆모습 해머는 두꺼운 몸통과 둥근 보라색 타격면이 보이도록 수정했습니다.

front.png는 제공된 67×73 PNG 원본입니다. 나머지 네 방향은 투명 원화를 기술적으로 추출한 뒤 같은 73px 높이와 발 중심축으로 맞췄습니다. 최근접 이웃 축소와 Point 필터를 사용하며, 큰 원화 여백을 런타임에 사용하지 않습니다.

생성 방식: built-in image_gen. 최종 원화 프롬프트와 수정 프롬프트는 [PROMPTS.md](PROMPTS.md)에 저장되어 있습니다. preview.png는 확인용 확대본입니다. 적용 리소스는 uploaded.json을 참고하세요.
