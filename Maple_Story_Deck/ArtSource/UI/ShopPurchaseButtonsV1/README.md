# 상점 구매 가능 버튼 초록색 통일

다이아 상품·대미지 스킨·펫 상점에서 구매 가능한 가격 버튼만 게임의 기존 초록색 계열로 표시합니다. 보유/장착 중인 항목, 스타터팩 전용 스킨과 판매 준비 중 항목은 원래 남색 리소스를 그대로 사용합니다. 상품 가격·버튼 위치·크기·문구·구매/장착 처리에는 손대지 않았습니다.

초록색 그림은 내장 image_gen 편집으로 제작했습니다. 로컬에 보관된 실제 남색 상점 버튼 화면을 형태 참고로, 기존 펫 하우스의 초록 버튼을 색상 참고로 사용했습니다. 금색 테두리와 양옆 장식을 같은 형태로 유지했습니다. 기존 버튼과 보이는 높이를 맞추기 위해 원본 비율을 유지해300×77로 줄이고300×92 투명 캔버스에 넣었습니다. Simple 방식으로 표시하여 늘어지는 테두리 조각이 없습니다. 최종 그림은 Parts/AvailableGreen.png, 원본은 Masters/AvailableGreen.png, 프롬프트는 generation-prompt.json에 있습니다.

수정한 게임 파일은 RootDesk/MyDesk/UI/ShopUI.mlua 하나입니다. SetPurchaseButtonAppearance()가 표시 색상을 공통으로 관리하며 ApplyProducts(), RefreshSkinCards(), RefreshPetShopUI()에서 구매 가능 여부를 전달합니다. 원래 남색 RUID는 ac665afab6d1482c91454ae5688dc950이며 변경하지 않았습니다. 네 가지 구매·장착 클릭 처리 함수가 원본과 동일함을 확인했습니다.

메이커 빌드 및 실제 재생에서 다이아 상품7개, 스킨8개, 펫5개의 가격 버튼을 확인했습니다. 구매 가능 항목은 초록색, 보유/잠금 항목은 기존 남색이며 각 탭의 원래 버튼 크기는 유지합니다. 보유·장착 데이터와 다이아가 변하지 않았고, 실제 구매/결제는 실행하지 않았습니다. 새 런타임 오류가 없습니다. 실제 화면과 확인 기록은 Verification/에 있습니다.
