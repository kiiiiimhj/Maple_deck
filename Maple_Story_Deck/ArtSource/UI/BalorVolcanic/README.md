# 볼케닉 스윙

- 조합: 디바인 스윙 Lv.5 + 홀리 차지 보유 + 웨폰 마스터리 보유.
- 기존 디바인 스윙 슬롯을 승계. 조합 후 디바인 스윙은 일반 선택지와 상점에서 제외.
- 스킬 Lv.1–3 기본 대미지: 260 / 280 / 310. 기본 쿨타임 4초.
- 해머 연출 2곳에 범위 피해. 같은 시전의 두 범위가 겹쳐도 몬스터당 1회 명중.
- 100% 스턴 2초 및 화상 2초. 화상은 명중 1초·2초 후 각각 적중 대미지의 25%.
- 화상은 기존 도트 덮어쓰기·사망 정리 규칙을 사용하며 맵·존·런·몬스터 생명주기 변경 시 취소.
- 카드 259 / 영구 스킬 목록 인덱스 149. 기존 인덱스 유지.
- 한국어·영어·일본어·중국어 간체·중국어 번체·스페인어 이름/태그/설명/레벨별 설명 추가.

## 이미지와 연출

- `icon.png`: 32×32, Point/Clamp. 원본 스킬 아이콘의 검을 해머로 교체한 편집 이미지.
- 생성 모드: built-in `image_gen`, edit. 편집 프롬프트는 `PROMPT.md`.
- 아이콘 RUID: `906ee573a65f43f48e212e6e60cfbba4`.
- 주 공격은 팩의 공식 해머 변형 `effect/1`(`6a81d7bd5dda4865b677e6c4eed0557a`) 사용.
- 보조 연출 `797e361515914a07844dc1f82fdd1326`, 타격 `b3f39f13319c40dd8c544cd54ed3e4f1`.
- 시전음은 제공된 강화 스윙 리소스, 타격음은 기존 생츄어리 해머 리소스. 게임 효과음 설정 적용.

## 검증

실제 메이커에서 조합 조건 누락/충족, 꽉 찬 슬롯에서의 승계, 3레벨 상한, 중복 광역 피해 방지, 범위 밖 제외, 화상 간격/총 피해/치명타, 맵 이탈 취소, 기존 디바인 스윙, 실제 스킬 탭 배치, 6개 언어 및 32px 리소스 로딩을 확인한다. 결과는 `verification.json`에 저장한다. 저장 후 소스 일치·UI 전체 엔티티와 UUID 보존 검증은 `manifest.json`, `saved-ui.json`에 남긴다.

기존 장비의 치명타 보너스를 보존한 상태로 비교 대상을 함께 타격해 실제 치명타 피해를 검증한다. 테스트 중 업적/조합 발견 저장은 차단하고 종료 시 원래 상태로 복원한다.
