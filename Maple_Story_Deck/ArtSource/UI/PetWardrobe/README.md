# 펫 옷장 및 전용 장비 아이콘

펫 하우스의 능력치 버튼 위에 노란 옷장 버튼을 배치했습니다. 현재 펫의 전용 장비 6개(모자·옷·목걸이 각 2종)를 표시합니다. 아이템을 누르면 왼쪽 아바타에 해당 부위를 미리 입히고 오른쪽에 구매/장착 창을 엽니다. 취소하거나 닫으면 실제 착용 모습으로 돌아옵니다. 미리보기는 장비 보유·착용 데이터와 분리되어 있습니다. 구매에는 기존 500 다이아 서버 구매 처리를 사용하며, 이미 보유한 장비는 장착으로 표시합니다. 이미 착용한 장비의 버튼은 비활성화합니다.

인벤토리 펫 장비 목록에는 보유한 장비만 표시합니다. 각 아이템 오른쪽 아래의 32px 원형 펫 얼굴 배지로 전용 펫을 구분합니다. 인벤토리 목록 아이콘은 다른 목록 아이템과 동일한 80×80이고, 상세창에는 별도로 만든 160×160 그림을 사용합니다. 목걸이는 전부 닫힌 고리 형태로 그렸습니다. 실제 착용 리소스와 대조해 뚱땅이 모자·옷의 남색/와인색, 크림색 선과 별 장식도 맞췄습니다. 실제 펫의 애니메이션·장비 합성 리소스는 바꾸지 않았습니다.

구매창은 기존 나무·금색·잎사귀 UI와 같은 원본을 재사용하며, 아이템 배경만 청록색·금색으로 새로 그렸습니다. 구매/장착은 초록색, 취소는 인벤토리 판매 취소와 같은 빨간색입니다. 가격에는 다이아 그림과 숫자만 표시합니다. 제목판·아이템창·능력치창·정보창·가격창·양쪽 버튼은 각각 독립되어 있습니다. 구매창 미세 조정은 UIInventory.mlua의 GetPetGearPurchaseLayout(), 옷장은 PetHouseUI.mlua의 InitializeWardrobe()에서 할 수 있습니다. 인벤토리와 팝업 그림 크기는 각각 80px와 160px로 별도 관리합니다.

메이커 실제 재생에서 현재 계정이 보유한 뚱땅이/더키 12개 장비의 미리보기·취소, 보유 장비 목록과 얼굴 배지, 66개 텍스처의 로딩/크기를 확인했습니다. 5펫 전체 30개 장비 및 잔액 경계·중복 클릭·보유 장비 장착 연결은 격리된 로직 검사로 확인했습니다. 기존 서버 결제·장비 선택 함수와 몸통/장비 렌더링 함수는 변경하지 않았습니다. 검증 과정에서 실제 구매나 다이아 차감은 실행하지 않았고, 전후 보유·착용·지갑 데이터가 동일함을 확인했습니다. 새 런타임 오류는 없었습니다. 실제 구매 후의 서버 결과는 기존 구매 처리로 연결되며 이번 검사에서는 실제 결제하지 않았습니다.

생성 방식: 내장 image_gen. 최종 생성 프롬프트와 원본은 ArtSource/PetEquipment/InventoryIconsV2/generation-prompts.json 및 Masters/, 새 아이템 배경은 ArtSource/UI/PetGearPurchaseV3/generation-prompt.json 및 Masters/에 보관했습니다. 등록 RUID와 해시는 asset-manifest.json에 있습니다. Verification/에는 실제 화면과 검사 결과를 보관했습니다.

## 옷장 버튼 스타일·위치 수정 (ButtonV2)

최신 옷장 버튼은 펫 하우스와 같은 둥근 금색 테두리의 노란색입니다. 옷장과 능력치는 x=628, y=222/154, 크기 132×56으로 정렬되어 제목판 아래에 여백이 있습니다. 버튼 글자는 능력치 Label의 스타일을 사용합니다. 원본·프롬프트·실제 화면과 검증 결과는 ButtonV2/에 보관했습니다.

## 세로 길이 축소와 공통 사각 BG (CompactV3)

최신 옷장은 높이560이며 제목과 하단 버튼까지 방 안의 표시 영역에 들어갑니다. 아이템 그림80px는 유지하고 모든 아이템에 동일한90px 금색 테두리·초록색 사각 BG를 사용합니다. 안내와 미리보기 해제를 한 줄로 배치했습니다. 최신 소스·공통 배경·배치·메이커 실제 화면과 결과는 CompactV3/에 있습니다.
