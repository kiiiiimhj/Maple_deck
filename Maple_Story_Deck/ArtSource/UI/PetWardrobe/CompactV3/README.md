# 펫 옷장 높이 축소와 공통 사각 BG

사용자가 표시한 빨간 영역에 맞춰 옷장 전체 높이를 730에서 560으로 약23% 줄였습니다. 폭과 중앙 위치는 유지했고 제목·설명·6개 아이템·아래 안내·미리보기 해제가 모두 창 안에 들어갑니다. 하단 안내와 버튼은 한 줄로 나란히 배치했습니다.

아이템 그림은 80×80 그대로 유지했습니다. 모든 아이템 뒤에 같은90×90 사각 BG를 공통으로 넣었습니다. 기존 인벤토리의 금색 테두리·초록색 칸 이미지를 재사용했으며 아이템마다 별도의 BG를 만들지 않았습니다. BG는 클릭을 가로채지 않습니다. 원본은 Parts/shared-item-background.png, 등록 RUID와 해시는 asset-manifest.json에 있습니다. 새 이미지 생성이나 업로드는 없습니다.

수정한 게임 소스는 RootDesk/MyDesk/Pet/PetHouseUI.mlua 하나입니다. InitializeWardrobe()의 배치와 RefreshWardrobe()의 얼굴 배지 위치·크기를 조정했습니다. 인벤토리 아이콘과 구매·장착 처리, 실제 펫 장비 합성은 그대로입니다.

메이커 빌드와 실제 재생에서 현재 보유한4펫의 전용 옷장 배치, 공통 BG와80px 그림, 창 경계·행 간격·하단 안내와 버튼의 간격을 검사했습니다. 전체30종 이름이36px 높이 안에 들어감을 확인했습니다. 미리보기·구매창 열기·취소와 원래 착용 상태 복원도 확인했고, 장비 보유/착용 데이터와 다이아는 바뀌지 않았습니다. 실제 구매는 실행하지 않았습니다. 새 런타임 오류가 없습니다. Verification/에 실제 화면과 검사 결과가 있습니다.
