# 펫 하우스 옷장 버튼 스타일·위치 수정

옷장 버튼을 인벤토리의 각진 버튼에서 펫 하우스의 둥근 금색 테두리 버튼과 같은 형태의 노란색으로 교체했습니다. 내장 image_gen으로 하우스 버튼과 같은 스타일의 작은 버튼을 편집했습니다. 작은 크기에서 테두리 이음선이 생기지 않도록 전용 132×56 PNG를 Simple 방식으로 표시합니다. 원본과 최종 프롬프트는 Masters/ 및 generation-prompt.json에 있습니다. 완성 PNG는 Parts/wardrobe-yellow-compact.png, RUID는 asset-manifest.json에 있습니다.

옷장과 능력치 버튼은 같은 가로축 x=628, 같은 크기 132×56입니다. 옷장의 y는 222, 능력치의 y는 154로 내려 제목판과의 여백 31, 버튼 사이 여백 12를 확보했습니다. 옷장 글자는 능력치의 원본 Label을 복제해 글꼴·외곽선·색·정렬·크기를 일치시켰습니다. 두 위치의 단위는 Room 기준 UI 좌표입니다.

수정된 게임 파일은 RootDesk/MyDesk/Pet/PetHouseUI.mlua 및 ui/PetHouseGroup.ui입니다. .ui는 공식 UIBuilder로 변경했습니다. 메이커 빌드와 실제 재생 화면에서 간격, 텍스처 로딩, 능력치 열기, 옷장 열기·닫기, 장비·지갑 상태 보존을 확인했습니다. Verification/에 실제 화면과 결과가 있습니다. 새 런타임 오류는 없습니다. 기존 구매 처리와 장비 리소스는 바꾸지 않았습니다.
