# 상점 펫 미리보기 UI

상점의 다이아·대미지 스킨 옆에 펫 탭을 추가했다. 구리·뚱땅·더키·부기만 표시하고 각 가격은 1,300코인이다. 오덕은 인게임 이스터에그 지급용이므로 판매 목록에서 제외했다. 카드에는 펫 원본 모습, Lv.1 기본 능력치, 스킬 아이콘·설명·주기와 가격을 표시한다.

현재는 UI만 연결했다. 카드 클릭은 판매 준비 안내를 띄우며 결제 창, 재화 차감, 펫 지급을 호출하지 않는다. 구매 등록 상품표와 서버 지급 로직은 변경하지 않았다. 향후 실제 판매 연결 시 ShopUI.GetPetShopCatalog의 항목과 등록 상품/서버 지급을 별도로 연결해야 한다.

화면은 기존 상점 아트와 엔티티를 런타임에 복제해 구성하며 원본 .ui 데이터는 수정하지 않았다. 런타임 탭과 카드 클릭 구독은 OnEndPlay에서 해제하고 생성한 엔티티를 제거한다. 검증은 메이커의 실제 탭·카드 클릭 이벤트로 진행했고, 오덕 미표시와 4종 가격, 안내 배너, 세 탭 전환, 클릭 전후 재화/보유 펫 불변을 확인했다. 마지막 카드 배치도 상점 패널 내부와 하단 안내 여백을 확인했다.
