# 뚱땅 왼쪽 눈: 원래 오른쪽 눈과 일치

사용자의 기준은 수정 전 오른쪽 눈입니다. 오른쪽을 새로 그리거나 파란색으로 바꾸지 않고, 모든 76개 몸 프레임의 오른쪽 눈을 수정 전 원본으로 복원했습니다.

문제가 있던 왼쪽 눈 20개 프레임에서만 작은 눈 안쪽을 보정했습니다. 원래 오른쪽 눈의 회색·민트색·크림색 반사광을 기준으로 만들고 같은 원본 팔레트에 맞췄습니다. 눈을 감거나 다른 표정을 짓는 나머지 56개 프레임은 수정 전 원본 그대로입니다.

내장 ImageGen으로 [눈 수정 가이드](eye-guide.png)를 만들었고, [프롬프트](prompt.txt)를 저장했습니다. 가이드에서 왼쪽 눈의 6×5 픽셀 부분만 분리해 기존 그림에 맞췄습니다. 게임에는 전체 가이드를 몸 이미지로 사용하지 않습니다.
