# 도토리 교환소 3단계 안내

교환소 왼쪽 위의 i 버튼을 누르면 다음 순서로 안내합니다.

1. 모험에서 등장하는 칠면조를 잡으세요.
2. 칠면조가 떨어트린 도토리를 모으세요.
3. 도토리 상점에서 아이템을 교환하세요.

펫하우스와 같은 85×85 i 버튼을 사용했습니다. 실제 칠면조·도토리·상품 이미지를 사용하고, 문구와 단계 숫자는 이미지와 분리된 텍스트입니다. 한국어·번체중국어·영어·일본어·간체중국어·스페인어를 지원합니다.

각 그림과 설명은 같은 카드 안에 있으며, 화살표 끝은 다음 카드의 보이는 테두리에 닿습니다. 다음 카드가 나타날 때 그 화살표도 같이 나타나고, 개별 확대 애니메이션으로 끝점이 어긋나지 않도록 구성했습니다. 화면을 누르면 같은 교환소로 돌아갑니다.

[한국어 실제 화면](guide-ko.png) · [대만어 실제 화면](guide-zh-tw.png) · [스페인어 실제 화면](guide-es.png)

기존 교환소 220개 요소를 보존한 결과는 `layout-preservation.json`, 버튼 연결·6개 언어·화살표 좌표·작은 캔버스 정렬·닫기·재화 보존 확인은 `verification.json`에 있습니다. 작게 만든 캔버스 검사는 실제 기기 전환이 아닌 런타임 캔버스 크기 모의 검사입니다.

새 화살표는 필요한 82×48 크기의 SVG 원본과 PNG로 제작했습니다. 기존 프레임·실제 게임 리소스를 재사용했으며 새 이미지 생성 도구는 사용하지 않았습니다. UI 편집에는 프로젝트 UIBuilder를 사용했습니다. 기존 교환소 위치·크기·재고·가격·구매 동작은 유지했습니다.
