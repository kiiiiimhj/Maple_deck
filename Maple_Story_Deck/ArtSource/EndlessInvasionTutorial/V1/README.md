## 권장 배치

도토리 교환소의 **현재 UI 파일**을 UIBuilder로 읽은 배치입니다. 기존 ArtSource/V2/layout.json과 달라 최신 UI 위치를 사용했습니다.
콘텐츠 크기 1520×1040, 원점 중앙, X 오른쪽+, Y 위쪽+입니다.

모든 파일의 피벗은 중앙(0.5, 0.5), 회전 0°, FlipX/FlipY=false 기준입니다.
화살표는 오른쪽 아래/왼쪽 아래 방향이 PNG에 반영되어 있어 추가 회전이나 반전이 필요 없습니다.
1번 화살표 끝은 2번 그림 왼쪽 경계에서 19px, 2번 끝은 3번 그림 오른쪽 경계에서 10px 떨어져 있습니다.
그림 영역 및 캡션 영역과 화살표 불투명 픽셀의 겹침이 없음을 검사했습니다.

그림 원본은 860×500으로 등록하고 430×250으로 표시하는 기준입니다. PNG 알파를 유지했습니다.
화살표는 기존 벡터 화살표 계열을 바탕으로 배치에 맞춰 새 곡선으로 제작했습니다. SVG 원본도 포함합니다.

## 안내 문구

1. 침식이 시작되면 / 몬스터가 강력해집니다.
2. 침식이 끝난 뒤 몬스터 100마리를 처치하면 / 다음 침식이 시작됩니다.
3. 침식 단계가 높아질수록 / 몬스터가 더욱 강력해집니다.

글자는 그림에 넣지 않았습니다. 숫자 100만 공통 시각 요소로 포함했습니다.
tutorial-layout-preview.png는 배치 참고용 시안이며 실제 게임에 적용된 화면이 아닙니다.

## 원본·검증

raw/는 내장 image_gen으로 만든 최종 투명 원본, prompts.json은 생성 및 수정 프롬프트입니다.
assets/에는 등록 PNG와 화살표 SVG가 있습니다. layout.json에 RUID·좌표·크기·화살표 끝점이 함께 있습니다.
기존 코드·UI·맵·모델 471개 파일을 작업 전후 해시로 확인했습니다. 바뀐 파일 0개입니다.
새 게임 로직 연결, 재생·저장·병합·푸시는 수행하지 않았습니다.
