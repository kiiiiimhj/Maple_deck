# 게임 오버 버튼 색상 수정

- 버튼 2개: 다시하기 초록색 / 종료 빨간색.
- 버튼 3개: 다시하기 파란색 / 이어하기 초록색 / 종료 빨간색.
- 종료 버튼 원본 `inventory-cancel-red-ui.png`의 실제 242×70 PNG에서 붉은 내부 색상만 변경했다. 크기 조정, 새로 그리기, 형태 변경 없음.
- 초록·파랑 모두 종료 버튼과 같은 투명도, 실루엣, 금테, 잎사귀, 광택과 명암을 사용한다. 내부 색상 변경 영역 밖의 모든 픽셀은 원본과 동일하다.
- 기존 UI 버튼 크기 330×104, 좌표, 텍스트, 비용 표시, 클릭 연결을 유지한다. 종료 버튼과 동일한 렌더러 설정과 58/58/18/18 슬라이스 경계를 사용한다.

## 파일

- `exit-red.png`: 종료 버튼 원본.
- `retry-blue.png`: 세 버튼 모드 다시하기.
- `retry-continue-green.png`: 두 버튼 모드 다시하기 및 이어하기.
- `pixel-verification.json`: 원본 픽셀 보존 검증.
- `layout-verification.json`: UI 크기·좌표·연결 보존 검증.
- `mode-verification.json`: 실제 모드 전환 메서드의 오프라인 검증.
- `maker-save.json`: 메이커 반영 및 저장 결과. 플레이 확인은 사용자에게 맡김.

## 제작 방식

처음에는 내장 imagegen으로 파란색 변형을 생성했으나, 종료 버튼과 형태가 완전히 같지 않아 적용하지 않았다. 사용자가 색상 이외에 정확히 동일한 원본 형태를 요구한 뒤, 최종 파일은 원본의 붉은 내부 픽셀 색상만 바꾸는 방식으로 제작했다.

최종 변환 조건: 내부 붉은 영역의 색조만 파랑 235도 / 초록 110도로 변경. 채도, 명도, 알파, 픽셀 위치, 외부 금테 픽셀은 그대로 유지.
