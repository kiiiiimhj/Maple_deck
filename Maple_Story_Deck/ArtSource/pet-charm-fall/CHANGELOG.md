# 뚱땅 매혹 — 공중 발판 낙하 수정

- 공중 타일 위 지상 몬스터가 기존 Y를 유지한 채 미끄러지는 문제를 수정. 매혹으로 이동하며 중력에 따라 아래층으로 내려와 실제 최하단 타일에 착지한다.
- 몬스터의 현재 X에서 맵의 실제 바닥을 읽으며 뚱땅의 고정 Y에 억지로 맞추지 않는다. 낙하 속도는 가속되며 최대 속도를 제한한다.
- 매혹이 떨어지는 도중 끝나도 착지까지 계속 처리하며, 착지 전 일반 공격/이동 루틴이 높이를 되돌리지 않게 했다. 종료 후 이동 기준점도 착지 높이에 맞춰 갱신한다.
- 일시정지에는 중력이 멈춘다. 기존 비행형의 매혹 이동, 뚱땅 연출/2초 소환, 신규 몬스터 유인과 U키 교대/3초 후 발동은 유지.

검증: 257개 동작 검사, 수정된 메서드 6개 문법 검사, 관련 없는 몬스터 메서드 189개 보존 확인. 실제 map04 공중 발판(y=1.18)에서 일반·엘리트·도중 매혹 종료 몬스터가 아래 바닥(y=-1.219)에 착지하는 것을 확인했다. 낙하 중 정지/재개, 매혹 종료 후 공중으로 되돌아가지 않는 것, HP 유지와 테스트 상태 정리까지 확인. 게임 코드의 빌드 오류 0, 최종 검증 구간의 런타임 오류 0. 초기 검증 데이터의 빈 배열 JSON 출력 오류 한 건은 검증 출력만 조정해 해결했다.
