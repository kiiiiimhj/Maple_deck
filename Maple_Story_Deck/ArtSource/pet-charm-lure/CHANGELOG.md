# 뚱땅 매혹 소환 개선 — 2026-10-12

- 뚱땅은 각 존 중앙의 실제 가장 낮은 타일 높이를 읽어 2초간 소환된다. 공중 발판이 있는 맵도 아래에서 위로 발판을 검사한다.
- 승인된 포효 그림을 유지하며 같은 크기로 세 번 통통 점프한다. 실제 알파 윤곽의 발끝을 기준으로 착지 위치를 맞췄다. 점프마다 하트 파장과 하트 투사체를 발사한다.
- 몬스터가 좌우로 왕복하는 동작을 없애고 뚱땅 위치로 초당 1 월드 유닛씩 천천히 모이게 했다. 도착하면 멈추며 매혹 해제 후 원래 위치로 순간 이동하지 않는다. 주기적인 이동의 기준점도 모인 위치에 맞춰 갱신한다.
- 뚱땅이 있는 2초 동안 새로 생성된 몬스터도 유인에 포함한다. 각 몬스터는 한 번 적용하며 일반 3초, 보스·엘리트 1.5초 매혹을 유지한다. 소환 종료 후 생성된 몬스터에는 적용하지 않는다.
- 구리 데굴데굴과 60초 자동 사용 주기는 유지. U키 교대/3초 후 미리보기 치트도 유지하며 소유·성장·장착 기록은 변경하지 않는다.
- 한국어·영어·일본어·중국어 스킬 설명을 소환/유인 동작에 맞게 갱신했다.

검증: 92개 동작 검사와 기존 펫 메서드 69개 보존 확인. 실제 메이커에서 U 발동, 좌우 몬스터의 단방향 유인, 늦게 생성된 몬스터, 2초 종료 후 신규 몬스터 제외, 매혹 시간/종료 위치/일시정지/HP 유지 확인. 189개 존의 실제 발판을 검사해 모두 중앙 최하단 타일과 일치(105개 존에는 여러 높이의 발판이 겹침). 에피1, 에피2 존4, 에피3 존4, 루디브리엄 map1 존5 및 map5 존10에서 실제 소환 프레임의 발 위치를 검증. 제작 코드의 빌드/런타임 오류 0. 임시 검증 코드에서 잘못된 사용자 참조 한 건이 있었으며 맵 루트 참조로 고쳐 확인했다. 테스트 몬스터와 상태를 정리해 로비로 돌려놓았다.
