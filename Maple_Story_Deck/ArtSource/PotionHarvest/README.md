# 포션 강화 미니게임

기존 광석 채집 조작을 포션 네 종류에 연결했습니다. 이벤트·펫하우스 파일은 수정하지 않았습니다.

| 포션 | 기본 시간 | 성공 보너스 | 처치당 드롭률 |
|---|---:|---:|---:|
| 흡혈 | 10초 | +5초 | 0.05% |
| 크리티컬 | 15초 | +5초 | 0.1% |
| 파워 | 20초 | +10초 | 0.1% |
| 경험치 | 20초 | +10초 | 0.1% |

먹으면 기본 효과가 즉시 시작됩니다. 기존 왕복 커서 조작으로 2~3개 목표를 모두 맞히면 보너스 시간을 현재 남은 시간에 더합니다. 한 번 빗나르면 즉시 실패하며 재도전하지 않습니다. 10초 동안 끝내지 못해도 실패하고, 기본 효과는 유지됩니다. 서버가 시간·세션·입력·중복 보상을 검증합니다. 다른 종류는 대기열로 처리하며, 같은 종류를 새로 먹으면 이전 도전은 취소됩니다.

포션 종류별 실제 아이콘과 코드로 그린 병 모양 벡터가 표시됩니다. 위·아래 텍스트에 검정 반투명 배경을 넣었습니다. 기존 광석 채집에도 10초 카운트다운과 텍스트 배경을 추가했습니다.

성공 시 포션이 짧게 반짝이고 +5초/+10초가 해당 버프 아이콘으로 날아가며 도착한 아이콘이 작게 튑니다. 시간 및 게이지는 성공 즉시 추가된 남은 시간으로 갱신합니다. 연출은 1.25초이며 맵 이탈·게임 종료·새 판에서 정리됩니다. 텍스트는 별도 UI이며 6개 언어를 지원합니다.

verification.json: 네 종류 성공, 10초 초과, 기본 효과 유지, 중복 보상 차단. input-and-ore-verification.json: 실제 UI 터치 경로, 한 번 실패 시 종료, 기존 광석 10초 실패. bonus-fx-verification.json: +시간 비행·아이콘 펄스·스케일 복구·HUD 게이지와 서버 시간 일치. final-verification.json: 새 판 초기화, 최종 오류 검사, 작업 파일 범위.
